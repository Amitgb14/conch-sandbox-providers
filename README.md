# conch-sandbox-providers (moved)

The registry moved to **[Amitgb14/conch-integrations](https://github.com/Amitgb14/conch-integrations)**,
which holds every kind of integration — CI services, ticket trackers,
notifications and sandbox providers — in one place.

This repository only keeps the old address working for conches released
before the move: a scheduled workflow copies the sandbox providers'
index (in the format those conches read) from
`https://amitgb14.github.io/conch-integrations/legacy/` to
`https://amitgb14.github.io/conch-sandbox-providers/`. Nothing here is
edited by hand; add or change a provider in conch-integrations.
